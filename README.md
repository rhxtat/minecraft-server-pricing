## 按人数和玩法选配置：MC 吃的是单核

Minecraft 对单核主频的敏感程度远高于核心数量。1.18 之后的新版本把单核需求拉得很高，用 2.9GHz 的老至强去开模组服，TPS 掉到 15 都不算意外。所以选套餐先看 CPU 单核能跑多少，再看内存。

- **i9-14900K / 14900KF**：单核最强一档，适合 1.20+ 大型模组整合包和 50 人起步的群组服。贵，但版本高、模组多的时候，差别就体现在 TPS 稳不稳。
- **Ryzen 7950X / 9950X**：5.7GHz，Zen5 架构，单核性能紧咬 i9，Linux 环境下有时还能反超，适合高版本「插件 + 模组」混开，性价比比 i9 更划算。
- **R9 5900X**：4.8GHz，中高版本模组服、小型群组、基岩版轻量服用它比较均衡，价格也压得住。
- **Gold 6146**：4.2GHz，纯净插件服够用，是低预算里比较体面的一档。
- **Platinum 8275cl / 8259cl**：3.9GHz，多核强、单核弱，适合低版本模组或高版本纯净插件服，还有积分兑换的免费套餐。
- **E5 2666v3**：2.9GHz，单核垫底，只建议超低预算的挂机服和低版本小型生存，同样有免费档。

一句话的选法：1.18+ 模组服优先 i9 或 Ryzen 7000/9000 系，低预算或老版本再考虑至强。3–5 人的原版生存，Gold 6146 或 Platinum 8275cl 这档 2核4G 完全带得动，没必要为「以后可能人多」提前加钱；10 人左右跑 150 个模组，就上 i9-14900K 的 2核4G；到了 20 人以上的大型整合包，直接看 4核8G 档。

## 面板服和 VPS，新手该买哪个

第一次开服，买面板服。

面板形态基于雨云自研的 MCSM 可视化面板，流程是：选机型下单，进控制台，在面板里选服务端类型（Paper / Spigot / Forge / Fabric），设端口，一键启动，把 IP 加端口发给朋友。面板还带自动备份、CPU 升降级和自带的 MySQL，带宽固定 50Mbps 上行。代价是没有系统级登录权限，玩不了内核级调优。

VPS 形态给 root，Windows 和 Linux 都能装，可以 SSH 或远程桌面进去。代价是 Java 环境、服务端 jar、启动脚本、防火墙规则都得自己来。会装 MCSM、会配 Nginx 反代的老手选 VPS 更自由，只是想和朋友联机，为「自由度高」多花的钱用不上。

## 便宜背后的三个限制

**NAT 共享 IP 不是独立公网 IP。** NAT 机型价格低，附送 15 个端口转发，纯 MC 服够用，但 25565 需要在面板里手动转发一次，官方教程两三步能搞定。有独立 IP 需求（比如对端口有特殊要求的服务）就得加钱升级到独立 IP 版本。

**防御按机房分档，不是无限防。** 不同机房提供的 DDoS 防护规格不一样，公开资料里有 100G 高防和 150G 共享防御两种说法，下单前按你选的机房确认实际档位，别把它当成能扛住任何攻击。

**峰值稳定性和大厂有差距。** 雨云是 2018 年成立、持有工信部 ISP、IDC、CDN 三证的国产云厂商，定位是性价比，不是高端商用。几十人、上百人同时在线的公益服，极端峰值时段的稳定性要自己评估；对 SLA 要求 99.99% 以上的商业服，不是它的目标场景。

试错成本这块，政策比较清楚：7 天无理由退款，每个账号限 3 次；几乎所有游戏云机型支持 1 元试用 24 小时，试用后不续费会自动回收；首月 5 折券有效期 30 天。三条叠起来，等于可以先花 1 元摸性能，再用 5 折券买一个月，跑不顺就退。

**首月 5 折券怎么领？** 通过推广链接注册并绑定微信，系统自动发券，有效期 30 天，云服务器、游戏云、虚拟主机几乎全线产品可用。

**券能和长期折扣叠加吗？** 能。季付 9 折、半年付 8 折、年付 7 折是常态化活动，与优惠券叠用，年付 7 折再加一张 8 折券，约合 5.6 折。

**2核4G 到底够几个人？** 原版或轻插件服，5–10 人在线问题不大；跑 150 个以上模组、十几人同时在线，2核4G 会吃紧，该往 4核8G 走。人数只是参考，模组数量和视距设置对内存的影响更大。

**NAT 机型朋友能连进来吗？** 能。把转发的公网地址加端口发给朋友即可，只是没有独立 IP，同一个 IP 下靠端口区分不同服务。

**动态计费适合谁？** 白天没人、晚上才热闹的休闲服，或者只在周末开的活动服。长期 7×24 满负载，固定套餐更省心也更可控。

**跑不顺能退吗？** 7 天无理由退款，每账号限 3 次；买之前也可以先用 1 元试用 24 小时。
